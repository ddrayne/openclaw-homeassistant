# v1.10.0-beta.1 — Holding line in the agent's own words (beta)

This is a **beta**. Install it from the integration's HACS page with **Show beta versions** turned on.

## What's new

- **The holding line is now the agent's own words.** When a request takes a while, you used to hear the same "On it — I'll let you know when it's done." every time. Now, if the agent has started replying ("Let me go through your inbox.") and then goes quiet for the **Grace period** (usually a slow tool call), the turn ends with what it said. The rest of the answer is announced when it's ready, without repeating that sentence.
- **No more long waits after a preamble.** Previously, any first words counted as "answering inline", so a preamble followed by minutes of tool work kept the satellite waiting for up to the **Agent Timeout** (300 s by default). Now it hands off to the background after the grace period.
- The configured **Holding phrase** is still used when the agent hasn't finished a sentence yet, or hasn't said anything at all.
- A deferred turn never reopens the mic, even if the holding line is a question.

**Tip:** ask your voice agent to say briefly what it's about to do before using a tool ("Let me check your calendar."). That sentence becomes the holding line.

## Feedback wanted

Does the hand-off happen at the right moments for your agent? If it defers too eagerly, try a longer **Grace period**. Please share what you find in an issue, with debug logs for `custom_components.openclaw` if something sounds wrong.
