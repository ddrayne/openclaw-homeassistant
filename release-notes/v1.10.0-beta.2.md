# v1.10.0-beta.2 — CJK fix, mTLS, clearable options (beta)

This is a **beta**. Install it from the integration's HACS page with **Show beta versions** turned on, then restart Home Assistant.

## Fixed

- **Chinese, Japanese and Korean replies now reach Assist** (#22). With **Strip emojis** on (the default), the emoji filter also removed every CJK character, so the whole reply was erased and Assist showed "..." with nothing spoken. If you use OpenClaw in Chinese, Japanese or Korean, this is the fix you need. The filter now only removes emoji, including newer ones it used to miss (🦞).
- **You can clear the gateway token and model override** under **Configure** (#26). Once set, they couldn't be emptied again.
- **Changing only the session no longer reloads the integration** (#28). The new session applies to the live connection straight away.

## New

- **Client certificates (mTLS)** (#27). If your gateway sits behind a proxy that requires a client certificate, set **Client certificate path** and **Client private key path** during setup or under **Configure**. Both are needed, together with **Use SSL**. The files are checked when you save, so a wrong path or a mismatched pair is reported in the form. The key must not be passphrase-protected. See the README section "Client certificates (mTLS)".

## Also in the 1.10 beta (from beta.1)

- **The holding line is the agent's own words.** When the agent says "Let me go through your inbox." and then works for a while, the turn ends on that sentence and the rest is announced when it's ready, instead of the fixed "On it — I'll let you know when it's done."
