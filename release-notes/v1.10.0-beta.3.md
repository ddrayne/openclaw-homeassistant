# v1.10.0-beta.3 — Thirteen languages (beta)

This is a **beta**. Install it from the integration's HACS page with **Show beta versions** turned on, then restart Home Assistant.

## New

- **Settings screens in twelve more languages:** German, French, Spanish, Italian, Dutch, Polish, Brazilian Portuguese, Swedish, Japanese, Korean, and Simplified and Traditional Chinese. Home Assistant picks the one matching your profile language.
- **Built-in spoken phrases follow the language you speak.** The holding phrase ("On it — I'll let you know when it's done.") and the short messages for a timeout, a connection problem or an empty reply are now spoken in the language of the request, in the same languages.

## Changed

- **The default holding phrase now changes with the language.** If you typed your own holding phrase under **Configure**, it is still used exactly as written. Only the untouched English default is replaced.

## Fixed

- **Follow-up questions in Chinese, Japanese and Arabic keep the mic open.** Only the Western question mark was recognised before.
- **The holding line works for Chinese and Japanese replies.** Their sentence endings weren't recognised, so the agent's own words were never used.

## Under the hood

- The repository now passes Home Assistant's hassfest and the HACS validation checks in CI, in preparation for the HACS default list.
- The license file is now the official Apache 2.0 text, so GitHub identifies it. The license itself is unchanged.
- A new README, with one-click install buttons.

## A note on the translations

They are machine-generated and have not been reviewed by native speakers. If something reads oddly in your language, a correction is very welcome: each language is one file in `custom_components/openclaw/translations/`, and the spoken phrases are in `custom_components/openclaw/phrases.py`.
