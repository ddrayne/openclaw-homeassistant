# v1.9.0 — Multiple agents, restart recovery, opt-in streaming

## Highlights

- **Several agents on one gateway** (#13). Add the integration again for the same gateway and pick a different **Agent** (or **Session Key**). Each one becomes its own conversation agent, so each can have its own Assist pipeline, TTS voice and wake word.
- **Survives Gateway and proxy restarts** (#20, #21). A Gateway upgrade or a reverse-proxy restart no longer leaves the integration unavailable until Home Assistant restarts. Reconnects back off from 5 s to 60 s instead of retrying every 5 s forever.
- **Full replies on OpenClaw 2026.10+** (#18, #19). Fixes voice satellites speaking only the first fragment of a reply ("He…").
- **Opt-in streaming responses.** The new **Streaming responses** option lets Home Assistant start speaking while the agent is still writing (HA 2025.6+, with **TTS max characters** at `0`). It's off by default.

## Fixed

- **Fast replies could be lost.** When the gateway's acknowledgement and the first reply events arrived together, the reply was dropped and the request waited for an answer that had already come.
- **Empty replies no longer leave Assist showing "..."** (#22). You now hear "I didn't get a reply from OpenClaw. Please try again." and a warning is logged.
- **The integration icon shows again** on Home Assistant 2026.3+ (#22).
- **A wrong token behind a token-checking proxy now opens re-authentication** instead of retrying setup forever. A token that is refused only briefly during a restart is retried first.
- **No more blocking-call warning** on every `wss://` connect.
- **The options form shows error messages** instead of raw keys, and `openclaw.reconnect` reports authentication failures clearly.

## Behaviour changes

- An HTTP 401/403 on connect is retried a few times (about 75 s in total) before it's reported as an authentication problem, because a restarting proxy can briefly refuse a valid token.
- Adding an exact duplicate (same gateway, agent and session) is rejected after the second screen of setup instead of the first.
- Streaming stays off unless you turn it on under **Configure**.

## Upgrade

Update through HACS, then **restart Home Assistant**. No configuration changes are needed. If the update doesn't appear, refresh the repository information in HACS.
