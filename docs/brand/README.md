# Brand: Claw House

The integration's symbol is a single open claw around a house-shaped cutout.
It is symbol-only: there is no wordmark.

| File | Use |
|---|---|
| `claw-house-blue.svg` | Main symbol, for light backgrounds |
| `claw-house-white.svg` | Reversed symbol, for dark backgrounds |
| `claw-house-black.svg` | One-colour version |
| `claw-house-small.svg` | Wider house opening, for 16–24 px |

The PNGs Home Assistant shows are in `custom_components/openclaw/brand/`:
`icon.png` and `icon@2x.png` (blue, 256 and 512 px) for light themes, and
`dark_icon.png` and `dark_icon@2x.png` (white) for dark themes.

## Palette

| Role | HEX |
|---|---|
| Main blue | `#007FAD` |
| Ink navy | `#122B39` |
| Ice | `#EAF6FA` |
| White | `#FFFFFF` |

## Rules of use

- Keep the house transparent; no lettering, shadows, gradients or outlines.
- Use white on dark backgrounds, not blue on navy.
- Keep the aspect ratio and leave clear space around the symbol.
- Prefer 24 px or larger; use the small drawing at 16–24 px.
