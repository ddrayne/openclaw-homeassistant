# Security policy

## Supported versions

Security fixes are made against the latest released version. Please reproduce a
problem on the latest version before reporting it when practical.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:
**Security → Report a vulnerability**. Do not put exploit details, credentials,
private data, or an affected user's information in a public issue.

If private reporting is unavailable, open a public issue containing only a
one-sentence summary and a way for the maintainer to contact you privately.

Include the affected version, security impact, reproduction steps, and any known
mitigation. Reports will be acknowledged and handled on a best-effort basis, with
fixes coordinated privately before details are published.

## Scope and testing

This policy covers code maintained in this repository. Vulnerabilities in Home
Assistant or OpenClaw itself should be reported to those projects.

Only test systems and accounts you own or have explicit permission to assess.
Avoid denial-of-service testing, accessing other people's data, and disrupting
live installations.
